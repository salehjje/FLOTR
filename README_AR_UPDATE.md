# FLOTR update
نسخة واجهات تجريبية: ترحيل النقاط بلا انتهاء، 1,000 نقطة = 1,000 د.ع، طلب سحب بحد أدنى 1,000 نقطة، لوحة مالك تجريبية للموافقة والرفض وتأكيد التحويل اليدوي.
الحالة محلية على الجهاز فقط وليست نظام أموال حقيقياً أو متعددة المستخدمين. قبل الإطلاق يجب ربط Firebase Auth وFirestore وCloud Functions، صلاحيات مالك خادمية وسجل معاملات وتدقيق. لا تجمع رقم البطاقة الكامل أو CVV أو PIN أو OTP.
