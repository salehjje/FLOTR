# FLOTR — مشروع Android أولي

تطبيق نقاط ومكافآت مستوحى من نمط تطبيقات المكافآت، مطور باستخدام Kotlin وJetpack Compose.

## فتح المشروع
1. فك ضغط الملف.
2. افتح Android Studio.
3. اختر Open ثم مجلد `FLOTR_Android`.
4. انتظر Gradle Sync.
5. شغّل التطبيق على محاكي أو هاتف Android.
6. لإنشاء APK تجريبي: Build > Build Bundle(s) / APK(s) > Build APK(s).

## الموجود حالياً
- واجهة رئيسية عربية RTL.
- بطاقة رصيد نقاط تجريبية.
- شاشة مكافأة يومية بتصميم أولي.
- شاشة محفظة.
- شاشة إحالات.
- شاشة حساب المستخدم.
- تنقل سفلي بين الأقسام.

## تنبيه مهم
هذا إصدار واجهات أولي (Prototype). زر التجربة يضيف 10 نقاط محلياً داخل التطبيق فقط.
لا توجد مصادقة أو قاعدة بيانات أو سحب أموال أو نظام إحالات فعلي حتى الآن.
لا تستخدم الرصيد التجريبي كرصيد مالي، ولا تطلق التطبيق للمستخدمين قبل بناء الخادم.

## البنية المقترحة للنسخة الإنتاجية
- Firebase Authentication: تسجيل الهاتف أو البريد.
- Cloud Firestore: ملفات المستخدمين وسجل النقاط.
- Cloud Functions: منح المكافأة بعد التحقق من وقت الخادم، ومنع تكرار المطالبة.
- Firebase App Check: تقليل إساءة استخدام واجهات Firebase.
- قواعد Firestore: منع العميل من تعديل الرصيد أو سجل المعاملات مباشرة.

## نموذج بيانات مقترح
`users/{uid}`

- pointsBalance
- referralCode
- referredBy
- createdAt
- lastDailyClaimAt

`users/{uid}/transactions/{transactionId}`
- type
- amount
- createdAt
- status
- referenceId
